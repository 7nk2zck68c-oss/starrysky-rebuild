Today's Starry Sky — 原本忠実ブラウザ版 v1

目的:
Scratch .sb3 のロジックを書き換えず、そのままScratch互換ランタイムでブラウザ実行します。

使い方:
1. index.html をブラウザで開きます。
2. 初回起動時はインターネット接続が必要です（TurboWarp Scaffolding 0.4.0 をCDNから読み込みます）。
3. .sb3本体は index.html 内にも埋め込まれており、同梱の .sb3 は照合・保管用の原本です。

このv1では、スマホ方位/ジャイロなどScratch原本に存在しない機能は追加していません。
まずScratch原本と同じ挙動であることを確認するための基準版です。
